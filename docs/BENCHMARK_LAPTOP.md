# Bayn model benchmark

Which Whisper model and which summary LLM to use, per language and per machine. Measured on the user's own recordings of the [corpus](CORPUS.md) (12 scripts: English, Arabic, and mixed Arabic with English key terms), with the same settings as the live demo.

> Generated by `python -m bayn.benchmark report` from data/eval/bench/ (raw transcripts and summaries stay on the machine that ran them).

> **Results from this machine without a GPU** (`cpu` profile: Whisper and the LLM both on the CPU, measured one at a time; in the live app they share it). Summary quality here comes from CPU runs.

**Machine:** 13th Gen Intel(R) Core(TM) i7-1355U (12 threads), no NVIDIA GPU. **Profiles:** `gpu` = Whisper float16 + beam 5 on the GPU, LLM on the GPU; `laptop` = CPU only with 4 threads (Whisper int8 + beam 1, LLM with num_gpu=0) to mimic a modest laptop. Desktop cores are faster than laptop cores, so laptop speeds are a best case; `cpu` = CPU only with all cores (for running this benchmark on the demo laptop itself - see `python -m bayn.benchmark --help`). Each case ran once: differences of a few points are noise.

**Metrics:** WER = word error rate, CER = character error rate (fairer for Arabic, whose spelling varies), key terms = share of each script's must-keep terms that survive (Rutherford, pi, chlorophyll, ...), RTF = processing time / audio length (below 1 = faster than real time). Summaries: facts = share of the topic's key facts present; invented = summaries with forbidden content (diagnoses, unsupported claims); a summary passes with ≥ 80 % facts, nothing invented, the right language and all sections.
